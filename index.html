Where I've worked

Senior Backend Developer LocusBlue (ScanX) Jun 2021 – Present

ScanX is a SaaS platform for processing drone, terrestrial and mobile LiDAR scans. I work across its Laravel API, Python worker, Vue/CesiumJS viewer and GIS tools.

  • Built a new Python processing pipeline to replace our PHP job runner. Ported the GIS processing jobs with matching output and released it to production in October 2026. Classification now runs much faster on both drone LiDAR and handheld-scanner data
  • Made the GIS processing jobs reliable on very large files. They split point clouds into chunks that run in parallel, keep an out-of-memory failure from crashing the whole job, and retry failed parts. Replaced a MATLAB cross-section classifier that ran for 8 hours and timed out on a 5.7 GB file with a parallel Python version
  • Improved point-cloud classification for roofs, power lines, poles, guardrails and vegetation. Optimized the PCA-based shape features, added guard rules against common misclassifications, and tuned the classification thresholds with Optuna against hand-labelled scans, running the training jobs on AWS Batch. Roof F1 went from 0.22 to 0.84 and power lines from 0.16 to 0.80
  • Made ground extraction 2–4× faster with a new pipeline. It downsamples the point cloud, runs PDAL SMRF tuned for area-based ground extraction, then restores the result to full resolution. Wrote a filter that removes false ground points caused by SLAM drift in backpack scans
  • Developed the Python processing behind 3D manual classification (brush and polygon tools in orthographic and perspective views), cutting the time to publish edits on a 617-million-point file from 28 to 19 minutes
  • Co-designed and developed the AWS Batch and SQS job setup. Jobs go to small, medium or large queues by file size, so quick jobs don't wait behind large scans, and standby workers run small jobs right away with no wait for AWS Batch to start a machine. Moving temporary storage from EFS to EBS fixed a slowdown that affected every user's jobs and let us raise the upload limit to 100 GB; removed 2 of 3 standby EC2 instances after finding they averaged about 5% utilization
  • Moved the whole processing pipeline from Windows LAStools under Wine to native 64-bit Linux
  • Worked extensively on the SaaS side of the Laravel API: multi-tenant accounts, roles and permissions, project and folder access, and subscription plans. Helped build subscription billing on Stripe, including trials, proration, plan changes and 3-D Secure
  • Rebuilt the main API on Laravel 10, then upgraded it to Laravel 12 with refresh tokens, rate limiting and XSS protection. Verified critical vulnerability findings in the API and UI and rotated development credentials after a security review
  • Built an admin dashboard that tracks each customer's uploads, projects and processing time against plan limits, flags heavy users and upsell candidates, and has per-account charts and CSV export
  • Built GIS and 3D features in the Vue and CesiumJS viewer: GeoJSON, KML and shapefile layers, measurements (distance, angle, height and area, with snapping to control points), height profiles, cross sections, 2D map mode, clipping, and cut-and-fill volume
  • Improved viewer performance by tuning level of detail and memory to each device's GPU, and upgraded Cesium from 1.109 to 1.131. Added intensity and elevation coloring, 3D Tiles 1.1 and Gaussian Splat output, and imports for LandXML, DXF, IFC and GLB models. Also built a prototype chat assistant on fine-tuned OpenAI models that could start processing jobs
  • Maintain the third-party integrations connected to ScanX, including GeoScan and Kumiki, and handle production support — monitoring customer jobs for failures, finding the cause and shipping the fix
  • Set up my own AI workflow with Claude Code and Codex: each task starts from a written plan, a second agent reviews the plan and code, and I review and test every AI-written change before it ships. Wrote 20 custom skills for routine tasks and a hook that stops agents from reading credentials
